Official **G3Viewer** downloads for Windows x64, macOS Apple Silicon, Android
and Raspberry Pi 4B with a 64-bit OS. Each link above selects the latest published
build independently, including alpha releases.

Current builds are **alpha**. macOS and Raspberry Pi are experimental; physical
validation remains pending. Pi is a `.deb` application package with a menu
launcher. USB preparation is a separate manual step documented in the package.

This repository contains installers, checksums and the download catalog; the
development project stays private. G3Viewer is not affiliated with DJI.
